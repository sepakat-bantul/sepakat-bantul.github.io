Siap Upload

Klik tombol di bawah untuk membuka folder penyimpanan bukti dukung. Setelah folder terbuka, Anda bisa langsung mengunggah file.

Langkah-Langkah
1

Klik Tombol di Bawah

Klik tombol hijau "Buka Folder Bukti Dukung". Folder akan terbuka di tab baru.

2

Upload File

Di dalam folder, klik "+ Baru" → Upload File, atau drag-and-drop file dari komputer ke folder.

3

Selesai

Tutup tab folder Drive. Bukti dukung sudah terunggah ke folder yang benar.

Format file yang diperbolehkan: PDF, Gambar (JPG/PNG), Excel, Word. Pastikan ukuran file tidak melebihi kuota Google Drive.

Folder akan terbuka di tab baru.

Jika Mengalami Kendala

Bagian ini hanya referensi. Kalau tidak ada masalah, tidak perlu dibaca.

Folder tidak bisa dibuka / muncul "You need access"?
Coba klik tombol lagi. Kalau masih tidak bisa, logout dari akun Google lain (sisakan 1 akun saja), lalu klik tombol lagi.
Tidak bisa upload / file tidak muncul setelah diupload?
Pastikan sudah login Google. Kalau muncul tombol "Login", klik dan pilih akun Anda. Tunggu 5-10 detik, lalu refresh halaman (F5).
Klik tombol tapi folder tidak terbuka?
Cek apakah browser memblokir pop-up. Kalau iya, izinkan pop-up dari situs ini, lalu klik tombol lagi.
